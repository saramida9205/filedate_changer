# 🕒 파일 및 폴더 날짜 수정기 (File Date Modifier)

윈도우 탐색기 스타일의 직관적인 인터페이스를 제공하는 파일/폴더 날짜(수정 날짜, 만든 날짜) 일괄 수정 도구입니다.

## 🚀 주요 기능
- **탐색기 스타일 UI**: 트리 뷰와 리스트 뷰를 통해 윈도우 탐색기처럼 익숙하게 파일을 찾고 관리할 수 있습니다.
- **날짜 일괄 수정**: 다중 선택한 파일 또는 폴더의 '수정된 날짜'와 '만든 날짜'를 동시에 일괄 변경합니다.
- **경로 기억 기능**: 자주 사용하는 폴더나 파일을 리스트에 등록하여 한 번에 처리할 수 있습니다.
- **탐색기 명령 지원**: 복사(Ctrl+C), 붙여넣기(Ctrl+V), 삭제(Del), 엔터(파일 실행/폴더 이동) 등 기본 단축키를 지원합니다.
- **안정적인 처리**: PowerShell 연동을 통해 시스템 날짜 정보를 정확하게 수정하며, 관리자 권한 및 읽기 전용 속성을 자동으로 처리합니다.

## 🛠️ 사용 방법
1. 프로그램을 실행합니다.
2. 좌측 트리 또는 중앙 리스트에서 대상을 선택합니다.
3. '경로기억' 버튼을 눌러 수정 대상을 확정합니다.
4. 우측 상단에서 원하는 날짜와 시간을 설정합니다.
5. '변경' 버튼을 클릭하여 작업을 완료합니다.
